# envboard UI 设计规范 v2.0 · Light

> 依据：本仓工作台的实际界面，源码在 `core/rs/crates/envboard-web/assets/`
> （`index.html` / `app.css` / `app.js`），逐条与 `app.css` 第 ① 区的令牌对应。
> 令牌的机器可读副本在 `docs/design/tokens-light.css`；它与 `app.css` 不一致时
> **以 `app.css` 为准**，并回改那份副本。
> 转换记录：由 v1.0 深色版整体迁移为明亮主题，映射表见下面的第 3 节。
> 适用：envboard 工作台及后续同栈工具页面。
>
> 本文件只描述**已经实现**的界面。改界面时同步改本文件；若某条与本仓实现不符，
> 以本仓实现与实测为准，先把差异记下来再决定改哪一边。

## 0. 版本变更（v1.0 深色 → v2.0 明亮）

| 项 | v1.0 | v2.0 |
|---|---|---|
| 主题 | 深色（surface 越亮层级越高） | 明亮（卡片纯白 + 页面浅灰 + 1px 边框分层） |
| 表面层级表达 | 靠明度阶梯 + 阴影 | 靠 `--panel #ffffff` 与 `--bg #f4f6fa` 的明度差 + `--line` 边框；阴影仅用于浮层 |
| 文本灰阶 | 4 级（越暗越弱） | 4 级（**反转**：越浅越弱） |
| 语义色 | 高明度（`#4c8dff` / `#35c07f`） | 下调明度（`#2a5fe8` / `#15803d`），白底上仍 ≥ 5:1 |
| 阴影 | 黑色 20%–40% | 冷灰 `rgba(16,24,40,.06/.10/.16)`，禁用纯黑 |
| 组件结构 / 布局常量 / 间距 / 圆角 / 图标 | — | **不变** |

## 1. 本次升级改动总览（按模块归类）

### 1.1 页面结构

| 改动 | 旧版 | 新版 |
|---|---|---|
| 整体骨架 | 单页纵向文档流，4 卡片自适应栅格 | 固定框架：Topbar 52px / Sidebar 260px / Main / Logbar 240px（可折叠 36px），100vh 分区内部滚动 |
| 环境列表 | 7 列全宽表格，行内 5–6 个按钮 | 侧栏卡片式列表（状态点 + 名称 + 端口/规则），搜索框过滤，hover 快速启停 |
| 环境详情 | 无（信息挤在表格行） | 详情面板 + 三页签：概览 / 配置 / 规则。日志**不进页签**，由底部常驻日志栏承担，且跟随当前选中的环境切换 |
| 全局视图 | 规则库、对比均为页面内面板 | 顶栏切换三个视图：环境 / 规则库 / 跨环境对比 |
| 全局统计 | 无 | 顶部 4 张 StatCard（总数 / 运行中 / 异常 / 规则集），点击即筛选 |
| 日志 | 面板内 220px 只读文本框 | 底部常驻日志栏：事件类型过滤、关键词搜索高亮、自动滚动、导出、清空、折叠 |

### 1.2 组件体系

- 新增组件：Badge 状态徽章、StatCard、Tabs、InfoGrid、CmdCard（代理命令卡）、Toast（success / error / info）、EmptyState、RuleItem、搜索框、日志工具条。
- **刻意不做的两个组件**（早期稿子列过，权衡后否决，别再按旧稿实现）：
  - **Dropdown（⋯ 更多菜单）**：浮层要按锚点算坐标，而 CSP 不允许内联 `style`，
    滚动容器里还会被裁切。低频操作改为**就地展开一行**（`.detail-more`），
    键盘与读屏器也不必处理"浮层焦点陷阱"。
  - **ActivityList（最近操作）**：服务端不记录操作历史，前端自己攒一份会在刷新/重开页面后
    与事实不一致，比没有更糟。要看发生过什么，以日志栏为准。
- 升级组件：按钮全量接入 SVG 线性图标；输入框获得 focus 光环与字段级错误态（描边 + 下方原因文本）。
- 组件状态补齐：按钮 hover / active / loading / disabled；徽章四态；Tab 激活态；Toast 三型。

### 1.3 交互行为

- 操作收敛：行内多按钮改为「侧栏快速启停 + 详情页主操作 + 就地展开行收纳低频操作」。
- 护栏：删除环境 / 删除规则 / **重分配端口**等破坏性操作都走二次确认，并**写明后果**
  （重分配要说明端口变化会让客户端的 `export https_proxy=…` 失效）。
- 关键资产可复制：代理命令一键复制，按钮原地反馈「已复制」+ Toast。
- 日志排障链路：事件类型过滤 → 关键词搜索（命中高亮）→ 自动滚动开关 → 导出 / 清空。
  「清空」只清视图缓冲并同时暂停跟随（磁盘日志文件不动）。
- 反馈统一：所有操作结果走 Toast（**右下堆叠**，在日志栏之上），异步操作按钮进入 loading 并禁用。

### 1.4 视觉样式

- Token 60+：表面三级、四级文本灰阶（含"仅白系表面"的使用纪律）、语义色 bg(10%)+border(30%)
  三件套、阴影三级、布局常量、4px 间距基数、九档字号、按钮 / 输入框尺寸。
- 引入 SVG 图标体系（24 网格 / 1.8px 描边 / currentColor）。
- 状态可视化增强：running 圆点 2s 脉冲；hover 抬升 + shadow-sm。
- 等宽字体覆盖所有技术值（端口 / 命令 / 日志 / 规则 / 徽章 / 状态值）。

### 2.2 文本 / Border

|---|---|---|---|
| `--text` | `#141a24` | 主文本 | 17.5:1 |

| `--muted-2` | `#6b7688` | 占位符 / 时间戳 / 弱化信息 | 4.6:1 |
| `--line` | `#e2e8f0` | 默认边框 / 分隔线 | — |

### 2.3 主题 / 语义

| Token | 值 | 用途 | 对比度 |
|---|---|---|---|
| `--accent` | `#2a5fe8` | 主色：主按钮 / 选中态 / 焦点 / 链接 | 5.4:1 |
| `--accent-2` | `#1d4ed8` | 主色深变体：hover / 等宽强调值 | — |
| `--ok` | `#15803d` | 运行中 / 成功 / 日志 SUCCESS | 5.0:1 |
| `--warn` | `#b45309` | 不健康 / 警告 / 日志 WARN | 5.0:1 |
| `--bad` | `#c92a2e` | 错误 / 危险操作 / 日志 ERROR | 5.5:1 |
| `--purple` | `#7c3aed` | 规则集标识、日志分段标记行（两个固定用途，别再造第三个） | 5.7:1 |
| `--cyan` | `#0e7490` | 日志 INFO 级别（专用） | 5.4:1 |

**透明变体规则**：主色与语义色各衍生 `--*-bg`（同色 10% 透明填充，用于选中背景 / 徽章底 / 图标底）与 `--*-border`（同色 30% 透明描边，用于选中描边 / 徽章描边）。

**明亮主题三原则**
1. 语义色必须下调明度后使用，禁止直接复用 v1.0 深色版色值（`#4c8dff` 在白底上仅约 3:1）。
2. 表面层级靠「卡片白 + 页面浅灰 + 1px 边框」表达，不靠阴影堆叠。
3. 语义色只表达状态，禁止装饰使用；`--purple`（规则集 + 日志分段标记）、`--cyan`（日志「运行」事件）为专用色。

**文本**

```
--text         #e6e9ef → #141a24
--text-2       #c4cbd8 → #3d4757
--muted        #9aa3b2 → #5f6a7c
--muted-2      #6b7384 → #6b7688
```

> 注意：文本层级在明亮主题下**反转**——深色主题越暗越弱，明亮主题越浅越弱，不可按亮度机械映射。

**主题 / 语义**

```
--accent       #4c8dff → #2a5fe8
--accent-2     #6ba0ff → #1d4ed8

--warn         #e0a13a → #b45309
--bad          #e2565a → #c92a2e
--purple       #a78bfa → #7c3aed
--cyan         #22d3ee → #0e7490
```

**迁移方式**：`app.css` 只需替换 `:root` 中的 token 值，组件层 class 与 DOM 结构零改动。若需保留深色主题，把旧值挂到 `[data-theme="dark"]` 选择器，通过 `<html data-theme>` 切换；组件层禁止写死十六进制色值，一律 `var(--token)`。

## 4. 字体 Typography

| 层级 | 规格 | 用途 |
|---|---|---|
| 品牌标题 | 15px / 700 / 0.02em | 仅顶栏品牌字 |
| 面板标题 | 17px / 600 | 详情面板标题（环境名用等宽） |
| 区块标题 | 13px / 600 | 卡片内小节标题，左侧 3px 主色竖条 |
| 统计数值 | 22px / 700 等宽 | StatCard 数值 |
| 正文 | 13.5px / 400 / 行高 1.55 | 全局正文基准 |
| 辅助 | 12 / 11.5px / 400 | 标签 / 提示 / 元信息 |
| 技术值 | 11.5–12.5px 等宽 / 行高 1.6 | 端口 / 命令 / 日志 / 规则名 / 状态值 |

- UI 字体栈：`-apple-system, "Segoe UI", "Noto Sans SC", system-ui, sans-serif`
- 等宽字体栈：`ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace`
- 规则：所有面向机器的字符串必须等宽；人机标签与正文用 UI 栈。
- 明亮专项：正文优先取 `--text-2` 而非 `--text`，避免纯黑在白底上的刺目感；`--text` 留给标题与需要强对比的短文本。

## 5. 间距 / 圆角 / 阴影 / 布局常量

**间距（4px 基数）**：`--space-1` 4（图标-文字微间距）· `--space-2` 8（组件内紧凑）· `--space-3` 12（列表项/表单内）· `--space-4` 16（卡片内边距基准）· `--space-5` 20（面板内边距）· `--space-6` 24（区块间隔）· `--space-8` 32（页面级留白）。新增间距一律 4 的倍数。

**圆角**：`--radius-sm` 6（按钮/输入框/列表项/菜单）· `--radius` 10（卡片/面板/命令卡）· `--radius-lg` 14（品牌区）· 4（菜单项/计数 chip/搜索高亮）· 999（pill 徽章）。同一层级必须一致。

**阴影（冷灰低透明）**：
- `--shadow-sm` `0 1px 2px rgba(16,24,40,.06)` — 卡片 hover 抬升
- `--shadow` `0 4px 12px rgba(16,24,40,.10)` — 常规浮起元素
- `--shadow-lg` `0 8px 24px rgba(16,24,40,.16)` — 下拉菜单 / Toast

规则：静态卡片默认无阴影、只靠 1px `--line` 边框界定；阴影只表达浮起层级，不用于装饰；禁止纯黑阴影。

**布局常量**（与主题无关，明暗共用）：`--sidebar-w` 260px · `--topbar-h` 52px · `--logbar-h` 240px（折叠 36px）· `--input-h` 32px · `--btn-h` 30px / `--btn-h-sm` 24px。

**断点四档**：1200px（StatCard 4→2 列、InfoGrid 3→2 列、隐藏品牌副标题）、900px（单列纵向流、
侧栏限高 38vh）、720px（隐藏版本徽章、视图切换只留图标）、640px（统计卡单列、隐藏日志搜索框）。
720 这一档是硬需求不是凑数：顶栏固有最小宽度 721px 且没有横向滚动，比它窄时溢出部分会被
`body` 的 `overflow: hidden` 裁掉且滚不到（实测 720px 已溢出 1px，681px 起刷新按钮完全移出视口）。

## 6. 图标 Icons

- 规格：24 网格线性图标，描边 1.8px，圆头圆角，`fill: none`。
- 尺寸三档：14（按钮内）/ 16（默认）/ 18（统计卡）。
- 颜色一律 `currentColor` 随文本继承，明亮主题下默认呈现 `--text-2`；禁止为图标单独指定颜色；危险图标仅在 danger 语境呈 `--bad`。
- 基础集：新建、搜索、刷新、复制、启动、停止、重启、编辑、删除、导出、清空、警告、信息、更多（⋯）。
  「设置」与「文件」目前**没有对应界面**，所以不定义这两个图标 —— 定义了也是死符号。
- 图标文件本身与主题无关，明暗切换零成本。

## 7. 组件规范与状态

### 按钮 Button
- 变体：primary（实心 `--accent` + 白字，5.4:1，每视图最多 1 个）/ default（白底 + `--line`）/ ghost（透明）/ danger（白底 + `--bad` 字）/ icon-btn（30×30）。
- 尺寸：默认高 30（padding 6–7/12）；sm 高 24、字号 12；图标按钮 30×30。
- 状态：hover 背景 `--panel-hover` + 描边 `--line-2`；active 下移 1px；异步操作 loading + 禁用；禁用透明度 0.45。

### 状态徽章 Badge
- 结构 = 6px 状态圆点 + 文本（等宽 11.5px），高 24，pill 圆角。
- 四态：running（ok bg/border + 脉冲）/ stopped（`--panel-2` + `--muted`）/ unhealthy（warn）/ error·port_conflict（bad）。
- 徽章写**中文标签**（运行中 / 已停止 / 不健康 / 配置未生效 / 端口冲突 / 启动失败），
  原始状态值放 `data-health` 供断言与排障 —— 徽章上直接写 `config_mismatch` 等于没写。
- 底为语义色 10% 填充 + 30% 描边，文字取语义色原值（均 ≥ 5:1）。
- 异常态必须同时给出原因文本与建议动作，禁止只靠颜色。

### 输入框 Input
- 高 32，底 `--bg-3`，描边 `--line`，占位 `--muted-2`（4.6:1）。
- focus：底色转 `#fff`、描边转 `--accent` + 3px `--accent-bg` 光环；错误：描边转 `--bad` + 下方 11.5px `--bad` 错误文本。

### 标签页 Tabs
- 激活 = 文本 `--accent` + 底部 2px `--accent` 下划线；默认 `--muted`，hover `--text`。
- 计数 chip 用 `--panel-2` 底 / 4px 圆角，激活时转 `--accent-bg` 底 + `--accent` 字。
- Tab 条底色 `--bg-2`，与内容区 `--panel` 形成一层弱区分。

### 轻提示 Toast
- **右下堆叠**（`--logbar-h` 之上、`right: --space-4`），宽随内容、上限 380px，
  ok/info 2.6s 自动淡出、bad 6s（错误要多留一会儿），0.18s 右滑入场。
- success / error / info 三型：白底 + 语义色 30% 描边 + shadow-lg；同屏最多 3 条。

### 日志行 Log Line
- 结构 = 时间戳 + peer（`--muted` —— 日志栏底色是 `--bg-2`，`--muted-2` 在这里只有 3.91:1 不达标）
  + 事件类型标记（定宽 44px 语义色）+ 正文（`--text-2`），行高 1.65，hover 背景 `--panel-hover`；
  搜索命中 = `--accent-bg` 底 + `--accent-2` 字（底取令牌里那档 10%，不要在组件里另写一个透明度）。
  时间戳**允许为空**：数据源只在 `client connect` 行写时间戳，请求/响应行本来就没有，
  空着保持列对齐即可，不要伪造时间。
- 标记色按**事件类型**取（数据源里没有日志级别，见 1.3 的排障链路）：
  请求 `--accent` / 响应 `--ok`（失败转 `--bad`）/ 连接 `--muted` / 运行 `--cyan` / 异常 `--bad`；
  分段标记行用 `--purple`。
- 日志区底色 `--bg-2`，与上方 `--panel` 内容区区分。

### 其余组件
- **就地展开行**（取代早期稿子的 Dropdown）：`--bg-3` 底 + 下边框，与主内容同一层，
  不浮起、不遮罩、无坐标计算 —— 见 1.2 的取舍说明。
- **EmptyState**：40px 图标（50% 透明）+ 13px 说明 + 12px 次级指引，居中。
- **StatCard**：38px 圆角图标底（`--*-bg`）+ 22px/700 等宽值 + 12px 标签；hover 抬升 1px + shadow-sm；可点击筛选。
- **InfoGrid**：1px `--line` 缝隙网格；label 11.5px 大写 + value 14px 等宽。
- **CmdCard**：`--bg-3` 底；命令 12.5px 等宽置于 `--panel` 代码块；右上角常驻复制按钮。
- **ActivityList**：28px 圆角类型图标底 + 动作 13px/500 + 时间 11.5px 等宽 `--muted-2`。

## 8. 使用约束

**工程硬约束**
1. 零构建链：原生 HTML/CSS/JS，禁止框架 / 打包器 / WASM。
2. 资产 3 文件（index.html / app.css / app.js），`include_str!` 内嵌。
3. CSP 严格：无 `unsafe-inline`，index.html 内联 `<script>` 计数保持 0。
4. API 兼容：UI 是纯展示层，不改 REST / SSE 契约。
5. 可测试性：DOM 保持可断言（data-* 标记、语义化 class）。
6. 主题切换（若保留深色）：用 `[data-theme]` 挂载 token 覆盖，组件层禁止出现十六进制色值。

**设计使用规则**
1. 语义色只表达状态；`--purple` 专属规则集与日志分段标记、`--cyan` 专属日志「运行」事件。
2. 异常态三通道：颜色 + 文本原因 + 建议动作，缺一不可。
3. 破坏性操作必须二级确认并写明后果。
4. 技术值一律等宽。
5. 对比度底线 WCAG AA：正文对 `--panel` ≥ 4.5:1（实测 17.5 / 9.4 / 5.5 / 4.6）。
6. 明亮专项：禁止沿用深色版语义色值；禁止纯黑 `#000` 文本与纯黑阴影；静态卡片靠 1px 边框分层。
7. 反馈只允许 Toast + 按钮 loading/disabled，禁止原生 alert/confirm。
