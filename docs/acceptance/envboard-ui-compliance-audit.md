## 0. 审计结论速览

| 维度 | 是否合规 | 结论 |
|---|---|---|
| 布局与间距 | **部分违规** | 框架合规；但出现规范明确禁止的孤立 px（6px/2px/3px/5px） |

## 2. 违规清单（按页面/区域分组）

> 每条格式：**位置 · 问题描述 · 违反规范要点 · 修改建议**。行号指向线上 `app.css`。

### A. 顶栏（Topbar）

- **A1 · 顶栏 `view-switch` 与连接状态同区并列（187 行 `.topbar-right`）**
  - 位置：`index` 顶栏右侧
  - 问题：导航（视图切换）与 SSE 连接状态/能力指示混在同一顶栏行，语义两维并列，信息层级略混。
  - 违反：信息层级清晰度（非硬规范，属体验优化）。
  - 建议：将连接状态收为顶栏最右一个低强调指示器（已有 `.conn-dot` 小圆点），与视图切换视觉权重拉开（如仅用 6px 圆点+tooltip，不加文字 pill）；无需大改。

### B. 侧边栏（Sidebar）

- **B1 · `.env-main` 内部 `gap: 2px`（236 行）**
  - 位置：侧栏环境项（名称/元信息两行）
  - 问题：2px 非 4 的倍数，偏离"间距 4px 基数"。
  - 违反：ui-spec §2「间距只取 `--space-1…8`，不出现孤立值」。
  - 建议：改为 `var(--space-1)`（4px）或 `2px`→`4px`。

- **B2 · 侧栏环境项快速启停按钮默认隐藏（259–262 行）**
  - 位置：`.env-quick { opacity: 0 }`，仅 hover/focus-within/is-busy 显示
  - 问题：键盘 Tab 聚焦时 `:focus-within` 会显示（已覆盖），但纯鼠标静止态下"启动/停止"入口不可见，可发现性弱。
  - 违反：可发现性（非硬规范）。
  - 建议：保持隐藏逻辑（避免 clutter），但在选中项（`.is-active`）常态显示快捷按钮；或 hover/focus 外增加"选中即显"。

### C. 主区 · 统计卡（Stats grid）

- **C1 · `.stat-card` 圆角用 `--radius`(10px) 而非 `--radius-lg`(14px)（324 行）**
  - 位置：主区顶部 4 张统计卡
  - 问题：卡片类容器使用中等圆角，与规范"卡片用 lg"不一致（同见 D1）。
  - 违反：ui-spec §2 圆角纪律"同层级必须一致（卡片用 lg）"。
  - 建议：统一为 `var(--radius-lg)`。

### D. 主区 · 环境详情 / 表单（Detail / Form）

- **D1 · 详情面板与命令卡圆角偏离规范（panel 301 行 / detail 355 行 / cmd-card 442 行 / empty-icon 713 行）**
  - 位置：详情面板、命令卡、空状态图标
  - 问题：均为卡片类容器却使用 `--radius`(10px)；规范明确要求"卡片用 lg(14px)"。
  - 违反：ui-spec §2 圆角纪律。
  - 建议：全部改 `var(--radius-lg)`，与统计卡一并统一（C1）。

- **D2 · `.form input` 垂直内边距 `6px`（480 行）**
  - 位置：所有输入框/下拉/文本域
  - 问题：`padding: 6px var(--space-2)`——**6px 是规范点名禁止的孤立值**（"不出现 6px、15px 这类孤立值"）。
  - 违反：ui-spec §2 间距纪律（明确列举）。
  - 建议：改为 `var(--space-2)`（8px）上下内边距，或引入 `--space-1_5` 这类非标档前先确认与 4px 基数冲突——直接取 8px 最稳。

- **D3 · 破坏性删除按钮静态区分弱（535–536 行 `.btn.danger`）**
  - 位置：详情操作区 / 规则项的删除按钮
  - 问题：`.btn.danger` 仅 `color: var(--bad)`，边框与背景与中性按钮完全一致；静止态下"删除"与"编辑/复制"视觉权重相同，仅靠红字+图标区分，误触风险高。
  - 违反：交互最佳实践；ui-spec §4 强调破坏性操作需强确认（虽有二次确认，但首击入口仍弱）。
  - 建议：静止态即给 danger 按钮 `background: var(--bad-bg); border-color: var(--bad-border);`（hover 再加深），或至少加 `border-color: var(--bad-border)` 让其从一排中性按钮中凸显。

- **D4 · 锁定的输入框仅靠颜色区分（501–505 行）**
  - 位置：运行中环境的只读字段（如端口）
  - 问题：`:disabled` 用 `color: muted-2 + bg panel-2 + cursor: not-allowed`，区分度足够；但无边框/图标进一步标识"为何不可编辑"。
  - 违反：无（已达标），列为可优化。
  - 建议：可选加一个禁用原因 tooltip 或弱化边框，明确"运行中锁定"。

### E. 主区 · 信息网格 / 徽章 / 规则 / 对比

- **E1 · `.info-cell` 内部 `gap: 3px`（426 行）**
  - 位置：详情信息网格（标签/值两行）
  - 问题：3px 非 4 倍数。
  - 违反：ui-spec §2 间距纪律。
  - 建议：改 `var(--space-1)`（4px）。

- **E2 · `.badge` 内部 `gap: 5px`（547 行）**
  - 位置：所有徽章（状态/标签）
  - 问题：5px 非 4 倍数。
  - 违反：ui-spec §2 间距纪律。
  - 建议：改 `var(--space-1)`（4px）或 `--space-2`（8px，若需更松）。

- **E3 · `.info-grid` 用 `gap: 1px` + 背景线模拟网格（419–420 行）**
  - 位置：详情信息网格容器
  - 问题：1px 是发丝线技巧（非间距语义），本身可接受，但无注释说明，易被误读为间距违规。
  - 建议：保留，加一行注释"1px 为边框模拟，非间距令牌"。

### F. 日志栏（Logbar）

- **F1 · 日志时间戳/连接 peer 文本对比度不达标（777 行 `.log-ts, .log-peer` + 726 行 logbar `--bg-2`）**
  - 位置：日志栏每一行的 `时间` 与 `peer` 标签
  - 问题：`color: var(--muted-2)`（#6b7688）渲染在 `.logbar` 背景 `--bg-2`（#e9edf4）上，实测对比度 **≈ 3.91:1**，**低于 WCAG 1.4.3 AA 要求的 4.5:1**。
  - 违反：WCAG 2.1 AA 1.4.3；同时违反自身"四级灰阶对比度承诺"（--muted-2 仅在白底承诺 4.6:1，未承诺在 `--bg-2` 上的表现）。
  - 建议（任选其一，按风险降序）：
    1. 日志行次要文本改用 `--text-2`（#3d4757，对 `--bg-2` ≈ 8.6:1），仍保持次级权重；
    2. 调深 `--muted-2` 使其在 `--bg-2` 上 ≥4.5:1（需同步复核其在白底/panel-2 上的表现，可能连带影响占位符）；
    3. 日志栏背景改用 `--panel`（白）而非 `--bg-2`，则 muted-2 回到 4.6:1。
  - 注意：此项为**唯一一处量化对比度不达标**，建议优先修。

- **F2 · `.chip.is-empty` 半透明致对比度下降（595 行）**
  - 位置：日志过滤 chip 中"当前无该类事件"的项
  - 问题：`opacity: 0.5` 使 muted 文字有效对比度跌至约 2.3:1（<4.5），筛选标签可读性弱。虽属"弱化空类别"语义，但仍为文本。
  - 违反：WCAG 1.4.3（若视为必要信息）。
  - 建议：弱化改用更克制方式——保留 `opacity: 0.5` 但**文字改用 `--muted-2` 之外不再降透明**，或仅弱化背景/边框而文字保持 `--muted`；或在规范中明确"空类别可低于 AA"。

- **F3 · 日志视图未显式声明 `aria-live="off"`**
  - 位置：`#log-view`
  - 问题：ui-spec §4 要求"日志视图 `aria-live='off'`"，`app.js` 未显式设置（默认即 off，但措辞未字面满足；且跟随开关的自动刷新需明确关掉读屏重放）。
  - 违反：规范措辞（功能性等效，属文档一致性）。
  - 建议：在日志容器上显式加 `aria-live="off"`（app.js 构建节点时设置）。

### G. 全局组件（Buttons / Toasts / Empty）

- **G1 · 字号无类型尺度令牌，且 10px / 10.5px 过小**
  - 位置：全局排版（log-kind `font-size: 10px` 781 行；chip-count `10.5px` 596 行；其余 11/11.5/12/12.5/13/13.5/15/17/20px 散落）
  - 问题：缺乏 `--text-xs/sm/base/lg/xl` 令牌，层级靠散落数值维持，跨组件不一致；两个 <11px 的字号在常规屏下偏小，弱光环境可读性差。
  - 违反：信息层级一致性（设计系统缺失，非硬规范但影响规模化）。
  - 建议：定义字号令牌（建议 `xs:11 / sm:12 / base:13 / md:14 / lg:16 / xl:20`），最小不小于 11px；将 10/10.5px 上提到 11px 或并入 `xs`。

- **G2 · 组件尺寸无统一尺度**
  - 位置：按钮 30/24/26px（514/537/538–539 行）、徽章 20（548）、chip 22（584）、计数 18（573）、stat-icon 34（332）、empty-icon 48（709）、log-search 180（754）
  - 问题：高度/宽度散落 px，无 `--size-*` 令牌；按钮高度 30px、sm 24px 低于常见 32–36px 基准。
  - 违反：组件一致性（设计系统缺失）。
  - 建议：至少统一按钮高度 token（如 `--btn-h: 32px`、`--btn-h-sm: 28px`），其余尺寸抽 `--size-*` 或接受为有意差异化（图标尺寸本就可分级）。

- **G3 · 移动端触控目标 < 44px（WCAG 2.5.5 AAA 建议）**
  - 位置：≤640 断点（915–921 行）未放大按钮
  - 问题：按钮/icon-btn/sm 高度 24–30px，移动端点按区不足 44px。
  - 违反：WCAG 2.5.5（AAA 级建议，非 AA 强制）。
  - 建议：≤640 断点将 `.btn` 高度提至 ≥40px、`.btn.sm` ≥36px；icon-btn 同比例放大。

- **G4 · 部分控件缺 `:active` 按下反馈**
  - 位置：`.seg-btn` / `.chip` / `.tab` / `.stat-card` 无 `:active`（仅 `.btn` 有 524 行）
  - 问题：切换类控件按下时无位移/底色反馈，触感弱。
  - 违反：交互一致性（轻微）。
  - 建议：为切换类控件补 `:active { transform: translateY(1px) }` 或底色变化。

- **G5 · `.btn:disabled` 仍响应 `:hover` 背景变化（523 + 525 行）**
  - 位置：禁用按钮
  - 问题：禁用态 `opacity: 0.45` 下 hover 仍改背景，产生"半透明变色"的轻微异常观感。
  - 违反：状态一致性（轻微）。
  - 建议：`.btn:disabled:hover { background: var(--panel); }` 或在禁用态抑制 hover。

### H. 响应式与无障碍（Responsive / A11y）

- **H1 · 窄屏未按规范收"抽屉"/"日志栏加高"（894–913 行）**
  - 位置：≤900 断点
  - 问题：ui-spec §3 描述"窄屏收侧栏为抽屉、日志栏加高"；实现为单列堆叠 + 侧栏 `max-height: 38vh`（906 行），日志栏仍固定 240px（未加高）。
  - 违反：ui-spec §3 响应式措辞（功能性等效但偏离描述）。
  - 建议：二选一——实现真正的抽屉（toggle 显隐侧栏），或回改 ui-spec 措辞为"窄屏改为单列纵向流，侧栏限高 38vh"，使规范与实现一致。

- **H2 · `tab` 下边距 `-1px` 负技巧（403 行）**
  - 位置：详情 Tabs
  - 问题：用 `margin-bottom: -1px` 让激活下划线压住卡片边框，可接受但缺注释。
  - 建议：保留并加注释说明意图。

## 4. 修复优先级建议

## 5. 真机复核建议（与项目验收 doctrine 一致）

本环境无头 Chrome 网络服务崩溃（`network_service_instance_impl` 崩溃，net error -2），**未能产出截图**。按 `docs/acceptance/m3-workbench.md` 的教义——"页面活着≠样式生效，必须读 `getComputedStyle` 并与令牌对齐"——以下条目建议在真实 Edge/Chrome（Windows 侧可直接开 `127.0.0.1:8900`）用控制台复核，确认本审计的"计算值"推断：

```js
// 在 127.0.0.1:8900 控制台执行
const cs = el => getComputedStyle(el);
// F1：日志时间戳对比度（muted-2 on bg-2）
const ts = document.querySelector('.log-ts');
console.log('log-ts color =', cs(ts).color, '| logbar bg =', cs(document.querySelector('.logbar')).backgroundColor);
// C1+D1：卡片圆角

// D2：输入框内边距
```
