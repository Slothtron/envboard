        常见问题

        • 手机 / 其他设备如何安装根证书？

          点上方「下载根证书」保存到设备，或「显示二维码」让手机扫码打开下载页；安装后在系统证书信任设置里手动开启信任。完成后把设备的 Wi-Fi 代理指向本机 IP 与对应环境端口即可。

        • Android 信任证书后不生效？

          Android 7.0 起默认不信任用户安装的 CA —— 应用的 HTTPS 流量仍走系统校验，属平台策略而非证书问题。设备已 ROOT 时，可把证书放进系统证书目录（/system/etc/security/cacerts）后重启；未 ROOT 时只有部分应用生效，这类设备建议配合 PC 端代理使用，功能不受影响。

        • iOS 信任证书后不生效？

          安装后还需到「设置 → 通用 → 关于本机 → 证书信任设置」打开该证书的完全信任开关。另外部分应用启用了证书固定（pinning），这类流量即使信任根证书也不会被解密。
