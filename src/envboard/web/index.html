规则文件

规则文件是 ip host… 形式的静态覆盖，按环境绑定 —— 切环境即切规则文件。 导入时 host… ip 反序写法同样接受；非法行会被自动忽略并逐条列出，不影响其余行。 环境自己的「静态 hosts 覆盖」优先于规则文件，两者都优先于 DNS 且永不过期。
